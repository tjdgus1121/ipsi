## GitHub Pages로 배포

1. GitHub에서 새 저장소를 만들고 이 폴더의 파일을 모두 올립니다.
2. 저장소 **Settings → Pages**에서 Source를 `Deploy from a branch`, 브랜치를 `main`, 폴더를 `/ (root)`로 고릅니다.
3. 1~2분 뒤 `https://<사용자이름>.github.io/<저장소이름>/` 주소로 열립니다.

## 새 버전을 올릴 때

새 날짜로 파일을 추가하고(예: `서연고_제시문면접_개념단어장_20261101.html`), `index.html` 안의 파일 이름 세 곳을 새 파일로 바꿉니다.
